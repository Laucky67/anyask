# Windows 划词取词范围扩展开发记录

- **日期**：2026-10-14
- **分支**：`codex/selection-uia-source`
- **状态**：实现完成，自动化检查通过，用户已进行部分应用实测。
- **本次目标**：结合鼠标位置和焦点元素，有限度查找父级文本容器，并随选中文字记录来源窗口、进程和选区矩形。

本次扩展了 Windows UIA 取词路径，改善“已选中文字但没有弹出药丸”的问题。实测中，多个原来无法捕获的位置已经可以捕获。

## 背景与问题

原 Windows 取词只读取当前焦点控件的 UI Automation 文本选区，并取第一个选区。它要求焦点控件本身支持文本选区接口；实际选中的文字可能由其他文本容器提供，导致取词失败。

本次沿用现有全局鼠标监听、拖选阈值、延迟触发和药丸窗口体系，重点修改取词环节。

## 关键设计与取舍

### 自动划词与快捷键采用不同查找顺序

自动划词优先读取鼠标松开位置的元素，再尝试焦点元素；快捷键优先读取焦点元素，再尝试鼠标位置。

这个差别来自两种操作的意图：拖选结束时鼠标位置通常与文字区域有关，而主动按快捷键时，鼠标可能已经移到其他地方，因此优先使用焦点元素。

### 有限度查找父级文本容器

每个候选元素先尝试读取自己的文本选区，失败后沿 UIA 控件视图向父级查找。最多读取起点加八层父级，共九个元素；不扫描子树。

父级元素的进程必须与起点的 UIA 提供者进程一致。遇到不同进程、未知进程或父级读取失败即停止该路径；起点属于自身进程时直接忽略。

层数上限控制遍历成本，进程边界约束文本来源。

### 通过原生窗口确认来源

开始读取时记录前台窗口和窗口进程。鼠标位置候选只有在该点的原生顶层窗口与前台窗口一致时才加入查找。

焦点候选会有限度向上寻找原生窗口句柄，以确认其所属顶层窗口。如果在查找范围内无法确认窗口，则允许用它与已确认鼠标候选的 UIA 进程一致性作为回退；已明确属于其他窗口的候选不会通过这个回退。

浏览器的 UIA 提供者进程可能与原生顶层窗口进程不同，因此分别记录两者，以顶层窗口确认应用归属，以提供者进程约束父级文本查找。

读取完成后再次检查前台窗口；若窗口已经改变，丢弃结果。候选起点被标识为密码控件，或无法读取该标识时，不从该候选开始查找。

### 记录文本来源与真实选区几何

取词结果由单一字符串扩展为文本和可选来源信息，并传入工具条待显示状态。来源信息包含：

| 字段 | 含义 |
|---|---|
| `process_id` | 提供选区的 UIA 元素进程 |
| `window_process_id` | 前台原生窗口所属进程 |
| `window_handle` | 原生窗口句柄，以十六进制字符串保存 |
| `rects` | 选区各行的屏幕物理坐标，包含位置和宽高 |

句柄使用字符串，避免传到 JavaScript 后产生整数精度损失。矩形保留多行结果和负坐标，支持位于主屏左侧或上方的显示器；过滤非有限数值及宽高不为正的矩形。

读取所有返回选区的非空文本，按返回顺序拼接，不额外插入分隔符。读取某段文本失败时不返回部分文本，继续尝试其他候选控件。矩形读取失败不阻止文本取词，来源中的矩形列表可以为空。

UIA 包装库当前没有封装选区矩形读取，因此通过公开的原生接口读取 SAFEARRAY，检查维度、元素大小和数组长度，并保证错误路径也释放数组。

选区矩形随文本保存在运行时状态，供后续定位和来源判断使用。药丸沿用鼠标锚点定位；非 Windows 路径及剪贴板回退的来源信息为空。

### 自动划词与快捷键保留不同的取词策略

自动划词只读系统选区，失败就不弹，避免向源应用发送按键。快捷键属于用户主动请求取词，UIA 失败后使用原有剪贴板回退。

## 测试方式与结果

本次采用先实现、再补充测试的方式。

新增五项 Rust 测试：

1. 起点无法取词时，可以回退到提供选区的父级。
2. 不读取不同进程或进程未知的父级。
3. 父级遍历遵守深度上限。
4. 不读取自身进程。
5. 保留多行矩形和负屏幕坐标，过滤无效几何数据。

前四项使用模拟元素树验证查找策略，第五项验证矩形数据处理。

验证结果：Rust 库测试 **45 项通过**，其中五项为本次新增；既有划词工具条和提示词前端测试 **11 项通过**；TypeScript 检查、Vite 构建、取词模块格式检查和 Git 差异空白检查通过。

## 回归检查

回归时检查浏览器单行和多行选区、不同应用的文本控件、连续划选，以及选中后将鼠标移开再按 `Alt+Q`。通过药丸复制并粘贴核对文本。

本次设计的核心是：根据触发意图选择查找入口，通过父级回退找到文本容器，用窗口和进程约束来源，并把文本与来源信息一起传递给工具条。
